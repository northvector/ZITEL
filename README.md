# Zitel Modem Terminal Manager

* Change LTE bands without contacting support
* Unlock advanced admin features (VPN, Band Lock, and more)
* Refresh your IP address quickly
* Simple terminal-based interface
<img width="1214" height="708" alt="image" src="https://github.com/user-attachments/assets/a468edda-eac6-4c13-a7df-a4e142b32707" />




## Requirements

Before using the application, make sure your modem matches the following conditions:

### 1. Modem Panel

Your modem web panel must look like this:

<img width="2560" height="1440" alt="image" src="https://github.com/user-attachments/assets/54f11529-bc4e-4169-bf78-a4cb36c7effa" />

### 2. Modem IP Address

The modem IP address must be:

```txt
192.168.0.1
```

## How to Use

1. Connect your computer to the Zitel modem
2. Make sure the modem IP address is `192.168.0.1`
3. Run the application
4. Enjoy full access to advanced modem controls

# مدیریت ترمینال مودم زیتل

* تغییر باند بدون نیاز به تماس با پشتیبانی
* فعال‌سازی قابلیت‌های ادمین مانند VPN و Band Lock
* تغییر سریع IP
* رابط کاربری ساده و ترمینالی

## پیش‌نیازها

قبل از استفاده از برنامه، مطمئن شوید که مودم شما شرایط زیر را دارد:

### ۱. پنل مودم

پنل مودم باید مشابه تصویر زیر باشد:

<img width="2560" height="1440" alt="image" src="https://github.com/user-attachments/assets/54f11529-bc4e-4169-bf78-a4cb36c7effa" />

### ۲. آدرس IP مودم

آدرس IP مودم باید روی مقدار زیر باشد:

```txt
192.168.0.1
```

## نحوه استفاده

1. کامپیوتر یا لپ‌تاپ خود را به مودم زیتل متصل کنید
2. مطمئن شوید آدرس مودم `192.168.0.1` است
3. برنامه را اجرا کنید
4. از امکانات پیشرفته مودم استفاده کنید 🚀
